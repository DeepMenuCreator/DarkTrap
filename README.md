# DarkTrap

Кастомный плагин PvP-трапок для **Paper 1.21.8** (Java 21, Maven).

## Возможности

- `/darktrap give <игрок> <трапка>` — выдать игроку предмет трапки.
- `/darktrap create <название>` — создать новую трапку (папка `Traps/<название>/config.yml`).
- Полностью настраиваемые трапки через YAML — без правки Java-кода.
- Защита существующих блоков (`protected-blocks` в основном `config.yml`).
- Трапка не ломает и не удаляет чужие блоки — восстанавливает **только свои**, причём
  восстанавливает **оригинальный** блок, а не воздух.
- Поддержка нескольких одновременно активных трапок.
- ActionBar-сообщение при запрете установки (мир, защищённый блок, пересечение
  с другой трапкой, неподходящее место).
- Корректная очистка активных трапок при выключении/перезапуске сервера.

## Структура после первого запуска

```
plugins/
└── DarkTrap/
    ├── config.yml
    └── Traps/
        ├── default/
        │   └── config.yml
        └── obsidian/
            └── config.yml
```

Новые трапки создаются командой `/darktrap create <название>` или вручную —
просто создайте папку `Traps/<название>/config.yml` по образцу и
перезапустите сервер (плагин).

## Сборка локально

Требуется JDK 21 и Maven.

```bash
mvn clean package
```

Готовый `.jar` появится в `target/DarkTrap-1.0.0.jar`.

## Сборка через GitHub Actions (без установки Java/Maven)

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки (включая `.github/workflows/build.yml`):

   ```bash
   git init
   git add .
   git commit -m "DarkTrap plugin"
   git branch -M main
   git remote add origin https://github.com/<ваш_аккаунт>/<репозиторий>.git
   git push -u origin main
   ```

3. Откройте вкладку **Actions** в репозитории на GitHub — сборка запустится автоматически.
4. После завершения сборки (зелёная галочка) откройте соответствующий workflow run
   и в разделе **Artifacts** скачайте архив `DarkTrap` — внутри будет готовый `.jar`.
5. Положите `.jar` в папку `plugins/` вашего Paper-сервера и перезапустите его.

## Permissions

| Permission        | По умолчанию | Описание                              |
|-------------------|--------------|----------------------------------------|
| `darktrap.use`    | все игроки   | Использование предметов-трапок         |
| `darktrap.give`   | op           | `/darktrap give`                       |
| `darktrap.create` | op           | `/darktrap create`                     |
| `darktrap.admin`  | op           | Полный доступ (включает все остальные) |
